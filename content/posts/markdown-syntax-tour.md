## 为什么单独写一篇语法说明

这个站的正文由一个自研的小型解析器渲染，它只支持一个刻意收窄的 Markdown 子集。写在这里的每一种语法都能被正确渲染，没有演示的（比如原始 HTML、LaTeX 公式、脚注）都不支持。本文既是说明，也是这个解析器的基准样例。

## 标题层级

正文从二级标题开始写，文章标题已经放在 frontmatter 里，所以一级标题不会出现在正文中。下面依次是三级到六级的样子，各级字号逐级收窄，列表缩进也随之变化。

### 三级标题

#### 四级标题

##### 五级标题

###### 六级标题

## 行内格式

*强调*、**加粗**、~~删除线~~ 是最常用的三种，相邻使用没问题，但本站不做嵌套：`**加粗里再套斜体**` 这种写法不会把内层解析成斜体，只会原样留下星号。行内代码用反引号包裹，适合写命令名和标识符，例如 `git commit --amend`、`npm run build`。这些符号只在成对出现时才生效，句子里单个星号会被当作普通字符。

## 代码块

三个反引号加语言名开始，三个反引号单独一行结束。支持的语言标识包括 bash、js、ts、python、rust、go、json、yaml、toml、sql、html、text 等，不在列表里的就用无语言名的写法，渲染成等宽块。

```bash
for f in content/posts/*.md; do
  echo "checking $f"
  head -n 1 "$f" | grep -q '^---$' || echo "$f 缺少 frontmatter"
done
```

```json
{
  "title": "一篇示例文章",
  "date": "2026-10-22",
  "tags": ["Markdown", "写作"],
  "draft": false
}
```

代码块内部的内容原样保留，反引号、星号、井号都不会被解析，所以想展示「未渲染的原始语法」时，把示例放进代码块最稳妥。

## 引用块

行首一个尖括号加空格即可，连续多行会合并进同一个引用。

> 引用块适合放原文摘录或者一句提醒自己别忘的话。
> 这是第二行，它们属于同一个引用。

## 无序列表与嵌套

行首是连字符加空格。嵌套时缩进两个空格，可以套很多层。

- 第一层的第一项
  - 缩进两格是第二层
    - 再缩进两格是第三层
- 回到第一层
- 列表项里可以放行内代码，例如 `~~删除线~~`，也可以放链接

## 有序列表

行首是数字加点再加空格，序号本身不必连续，但建议按顺序写，便于维护。

1. 先把稿子写完
2. 再对照本站语法清单检查一遍
3. 确认日期和分类无误后提交

## 任务列表

无序列表项前面加一对方括号，中间是空格或字母 x。

- [ ] 还没做完的事
- [ ] 另一件待办
- [x] 已经完成的事

## 表格

用竖线分隔单元格，第二行是表头分隔行，冒号控制对齐，分别在左、居中、右三种。

| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| 名称可以长一点 | 2026-10-22 | 3 |
| 表格语法 | 解析器 | 100 |

## 分割线

独占一行、前后各有一个空行的三个连字符渲染成分割线，用来切分正文里语气转折的位置。

---

## 链接

方括号里写文字，紧跟圆括号里的地址，支持站内相对路径和站外完整地址，例如 [CommonMark 规范](https://commonmark.org) 或者站内页面 [关于这个博客](post.html?id=hello-exicok-blog)。站外地址会自动带上 `target="_blank"`，`javascript:` 之类的地址会被替换成不可跳转的空链接。

## frontmatter 的写法

文件第一行是三个连字符，接下来若干行 `key: value`，再用一行三个连字符结束。正文里的分割线必须前后留空行，且不能是整个文件的第一个三连字符行，否则解析器会误认为元数据边界。
